# Changelog

## [1.1.0] — 2026-11-20

### Изменено
- Маршруты вынесены в Flask blueprints (`routes/`), `server.py` сокращён до фабрики и запуска.
- Все POST-формы защищены CSRF-токеном; API-скриптам нужен `X-CSRF-Token`.
- Повторный `POST /setup` больше не может перезаписать администратора.
- Удаление канала очищает `data/hls/<id>` и `data/ticker/<id>.txt`.
- `/events?limit=...` не падает на некорректном значении.
- `create_channel` подставляет значения по умолчанию.
- Журнал `logs/events.jsonl` ротируется (5 МБ × 3).
- Добавлена лицензия MIT (LICENSE).
- Версия сервера приведена к `1.1.0`, добавлены `config.example.yaml` и этот CHANGELOG.
- Сборка: zip именуется по версии, в него попадают README/CHANGELOG/config.example,
  debug-APK по умолчанию не включается (`VHS_INCLUDE_APK=1` — только для локальной проверки).

### Исправлено
- Возвращён запуск `server.py` после рефакторинга.
- Smoke-тесты: 7 сценариев (setup, CSRF, каналы, HLS-очистка, страницы).

## [1.0.0] — 2026-11-02

- Первый публичный релиз: каналы из папок, IPTV, камеры, мозаика, EPG, оверлеи,
  HLS и multicast, Android TV клиент.
